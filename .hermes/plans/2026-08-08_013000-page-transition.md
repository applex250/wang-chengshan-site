# 页面切换体验优化 Implementation Plan

> **For Hermes:** 先修根因(资源/CLS),再做过渡动画;按任务逐个提交。

**Goal:** 消除从其他页面切回首页时的卡顿、白屏、内容跳变,让页面切换达到 Apple 官网级的丝滑体验(淡入淡出 + 微位移,300-500ms)。

**Architecture:** 分两层——(1) **根因修复**:移除被墙的外部资源(Google Fonts、jsdelivr CDN 本地化)、压缩 1MB 头像、图片加宽高占位,消除 FOUT/请求等待/CLS;(2) **过渡动画**:用现代浏览器原生 **View Transitions API**(`@view-transition { navigation: auto }`,零 JS 零依赖)实现跨页平滑过渡,旧浏览器自动降级。

**Tech Stack:** Jekyll(al-folio v1)静态站 / Liquid / SCSS / View Transitions API / PIL(图片压缩)

---

## 当前分析(调研结论)

**框架与路由**:Jekyll 静态 **MPA**,每次导航整页刷新——无 SPA 组件重复挂载问题,但存在整页重载白屏 + 资源重请求。GitHub Pages 托管,HTML 页无缓存(每次 200),`?v=hash` 资源可被浏览器缓存。

**卡顿根因(按影响排序)**:

| #   | 根因                                                                                                                                      | 现象                                                       |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| A   | **Google Fonts 被墙**(Roboto + Roboto Slab + Material Icons,`fonts.googleapis.com`)                                                       | 字体请求超时等待 → **FOUT 文字重排、布局移动、加载等待感** |
| B   | **jsdelivr CDN 依赖 7+ 项**(fontawesome / academicons / scholar-icons CSS;masonry / imagesloaded / **MathJax(4MB+)** / jquery JS)每页加载 | 大陆访问不稳定 → 卡顿、图标闪烁、白屏等待                  |
| C   | **首页头像 `prof_pic.png` = 1MB PNG**                                                                                                     | 切回首页重载+解码开销,hero 区顿感                          |
| D   | **无页面过渡**,整页直接替换                                                                                                               | 白屏、跳变、"销毁重建"感                                   |
| E   | profile 图等**无 width/height 属性**                                                                                                      | 潜在 CLS(布局偏移)                                         |

**已确认的好消息**:al-folio vendor 配置支持 `local` 本地化(`assets/vendor/`);`_config.yml` 的 `google_fonts`/vendor `url` 均可改为本地路径。照片墙 fixed 定位不占布局流(无 CLS 风险)。

## Task 1: 头像 WebP 化

**Objective:** 1MB PNG → ≤50KB WebP,消除 hero 重载开销。

**Files:** `assets/img/prof_pic.png`(保留或替换为 webp;about.md 的 image 字段同步)

**Step 1:** `python3` PIL:`prof_pic.png` → 最长边 400px → `prof_pic.webp`(quality 80),记录前后 KB。

**Step 2:** 改 `_pages/about.md` 的 `image: prof_pic.png` → `image: prof_pic.webp`(或新文件名);检查 figure 渲染是否自动带 width/height(无则 T6 补)。

**Step 3:** 提交 `git commit -m "perf: 首页头像 WebP 化(1MB→~40KB)"`

## Task 2: 移除 Google Fonts

**Objective:** 消灭被墙字体请求与 FOUT。

**Files:** `_config.yml`(google_fonts 段)、`_sass/_themes.scss`(字体变量)

**Step 1:** `_config.yml` `google_fonts.url.fonts` 置空或删除该 vendor 条目(验证渲染后 `<link>` 不再含 fonts.googleapis.com)。

**Step 2:** `_themes.scss` 字体变量改为系统栈:

```scss
--global-font-family: system-ui, -apple-system, "Segoe UI", Roboto, "Noto Sans CJK SC", "Microsoft YaHei", sans-serif;
--global-heading-font-family: "Noto Serif CJK SC", "Songti SC", Georgia, serif; /* 中文衬线兜底,零外部请求 */
```

(中文站:拉丁部分用系统字体,中文用系统 CJK,视觉基本一致且零外部依赖)

**Step 3:** 提交 `git commit -m "perf: 移除 Google Fonts 外部依赖(系统字体栈,消除 FOUT)"`

## Task 3: CDN 资源本地化

**Objective:** jsdelivr 三大每页 CSS 本地化,消除大陆不稳定依赖。

**Files:** `assets/vendor/{fontawesome,academicons,scholar-icons}/`、`_config.yml`

**Step 1:** 下载(本机 curl jsdelivr,失败则换源/unpkg 镜像):

- `@fortawesome/fontawesome-free@7.2.0` 的 `css/all.min.css` + `webfonts/*`
- `academicons@1.9.5` 的 `css/academicons.min.css` + `fonts/*`
- `scholar-icons@1.0.3` 的 `css/scholar-icons.css` + 字体文件

**Step 2:** 改 `_config.yml` 对应 vendor 的 `url.css` → `/assets/vendor/...`(注意 integrity 保留或同步更新)。

**Step 3:** 本地构建不可用 → 推 CI 验证产物 `main.css`/HTML 中 CSS link 指向本地路径。

**Step 4:** 提交 `git commit -m "perf: fontawesome/academicons/scholar-icons 本地化(去 jsdelivr 依赖)"`

## Task 4: 非必要脚本按需化

**Objective:** MathJax(4MB)等不用于首页的脚本不在首页加载。

**Files:** `_config.yml`(math/masonry 等按需开关,查证后定)

**Step 1:** 确认首页是否有数学公式(无)→ 查 `_config.yml` math 启用配置与按需加载机制(per_page 或 math: false 默认)。

**Step 2:** 若存在"每页都加载 MathJax"的全局开关,改为仅数学页面启用(或首页显式排除);masonry/imagesloaded 确认是否被照片墙/项目页使用,无则全局移除。

**Step 3:** 提交 `git commit -m "perf: MathJax 等非首页脚本按需加载"`

## Task 5: View Transitions 页面过渡

**Objective:** 现代浏览器原生跨页过渡(Apple 级丝滑),零 JS。

**Files:** `_includes/page-transition.liquid`(head 注入)、`_sass/_page-transition.scss`、`main.scss`

**Step 1:** head 注入(通过可覆盖的 head include 或 \_layouts 层):

```css
@view-transition {
  navigation: auto;
}
```

**Step 2:** 动画(300-400ms,opacity+transform):

```scss
::view-transition-old(root) {
  animation: vt-out 320ms cubic-bezier(0.4, 0, 0.2, 1) both;
}
::view-transition-new(root) {
  animation: vt-in 360ms cubic-bezier(0.4, 0, 0.2, 1) both;
}
@keyframes vt-out {
  to {
    opacity: 0;
    transform: translateY(6px) scale(0.995);
  }
}
@keyframes vt-in {
  from {
    opacity: 0;
    transform: translateY(10px) scale(0.995);
  }
}
@media (prefers-reduced-motion: reduce) {
  ::view-transition-old(root),
  ::view-transition-new(root) {
    animation: none;
  }
}
```

(时长在 300-500ms 内;只动 opacity/transform 不触发 reflow)

**Step 3:** 确认跨文档 View Transitions 兼容性:Chrome 126+/Edge/Safari 18+ 原生支持;旧浏览器自动无动画(正常跳转)。2026 年主流覆盖已足够,不引入 pjax 库(YAGNI)。

**Step 4:** 提交 `git commit -m "feat: View Transitions 跨页过渡(300-400ms,降级安全)"`

## Task 6: Hero 区域稳定性

**Objective:** 首页中间区域切换时零跳变(占位 + 无 CLS)。

**Files:** `_layouts/about.liquid` / figure 相关 include / `_sass/_memorial.scss`

**Step 1:** profile 图设置 `width`/`height`(figure 渲染后 img 自带则跳过;否则在 about.liquid 的 figure include 参数补上,或 CSS 固定 .profile img 尺寸占位)。

**Step 2:** `.post-header` 与 `.profile` 区加 `min-height` 占位(基于现有排版值,防止切换瞬间布局坍塌),并在 `_memorial.scss` 或新 scss 中实现。

**Step 3:** 提交 `git commit -m "perf: hero 区域尺寸占位,消除 CLS"`

## Task 7: 验证与发布

**Objective:** CI 全绿 + 线上产物逐项核对。

**Step 1:** `npx prettier . --check` 全绿。

**Step 2:** 推送,等 CI(Prettier + Deploy + broken links)。

**Step 3:** 抓 gh-pages 产物核对:

- `index.html` head:无 `fonts.googleapis.com`;`fontawesome/academicons/scholar-icons` 指向 `/wang-chengshan-site/assets/vendor/...`
- 头像:`.webp` 且带 width/height;大小 ≤50KB(gh api 查 size)
- `main.css`:含 `@view-transition` 与 `vt-out/vt-in` 动画
- MathJax 不在首页(若无公式)

**Step 4:** 用户强刷验收:其他页 → 首页,应见旧页淡出 + 新页淡入(约 350ms),无白屏、无跳变;老浏览器(若用)无动画但正常。

## 风险与权衡

| 风险                            | 对策                                                                                                                                 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 字体视觉变化(Roboto → 系统栈)   | 中文站主体是中文(系统 CJK),拉丁仅轻微变化;换取零外部请求与无 FOUT,值得。若坚持 Roboto 视觉,备选自托管 woff2(需能下载字体,执行时验证) |
| vendor 下载失败(jsdelivr 被墙)  | 尝试 unpkg/other 镜像;仍失败则保留 CDN 但加 `integrity` + 明确降级(至少 Google Fonts 必移除)                                         |
| View Transitions 旧浏览器不生效 | 自动降级为普通跳转,功能不受影响                                                                                                      |
| MathJax 按需改动破坏公式页      | 仅改"首页/无公式页不加载",公式页保留                                                                                                 |
| GitHub Pages 缓存旧资源         | `?v=` hash 版本参数会随构建变化,强刷可解                                                                                             |

## 开放问题

1. **字体方案**:接受系统字体栈(推荐,零依赖零风险)?还是自托管 Roboto woff2(视觉保持,需成功下载字体文件)?默认走系统栈,下载失败自动落回。
2. **vendor 本地化范围**:先做 3 个每页 CSS(fontawesome/academicons/scholar-icons);masonry/imagesloaded/MathJax 按实际用途按需(默认:MathJax 首页禁用,其余查证)。
